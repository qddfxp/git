# FreeCAD建模任务：带平底盲孔的正五棱柱

建一个正五棱柱，顶面中心打个平底盲孔，顶面外棱倒圆角。做完存文件，再跑验收。

## 脚本和调试

脚本可以先写，不用等 GUI。用 freecadcmd 无头模式把逻辑调通，这一步和 GUI 没关系。

脚本默认存 `E:\jiaobenmulu`。如果这个目录写不进去，排查一次还不行就先丢桌面 freecad 文件夹里，注明一下就行，别在这卡住。

## GUI 这边

先看看有没有残留的 FreeCAD 进程，有的话全部结束掉，再全新启动 FreeCAD 1.1.3。弹窗处理干净，切 Part Design 工作台。桌面 freecad 文件夹检查一下，缺了就建。

GUI 里只执行一次最终脚本，不在界面上反复调。同名 FCStd 直接覆盖，不另存版本。

## 尺寸

草图放 XY 平面，往 +Z 拉，底面在 Z=0。

- 正五棱柱：对边距 55 mm，高 30 mm，平边朝上（Y 轴正方向），中心对原点
- 顶面中心平底盲孔：直径 22 mm，深 12 mm，孔轴和棱柱中心轴重合
- 顶面外轮廓五条棱倒圆角 R3 mm，孔口棱不倒

## 建模规矩

全用 Part Design 原生特征，放同一个 Body，自动合成单一实体。Part 模块直接造几何体不行，布尔拼接也不行。

## 卡壳了

一个卡点最多想两个办法，第一个试两次没进展就换第二个，别重复已经走不通的路。脚本报错先查根因，改完整体重跑，不逐行打补丁。

## 交什么

两个脚本加一个模型文件：
- 建模脚本：只建模 + 存盘，不写合格判定
- 验收脚本：独立的，从磁盘重新打开 FCStd 回读，按 Checklist 逐项出结论
- 模型文件：`pentagon_prism_with_hole.FCStd`，存桌面 freecad 文件夹

交付时给文件完整绝对路径 + 模型树特征排列顺序。
